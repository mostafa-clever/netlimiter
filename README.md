# حارس الواي فاي (WifiGuard)

تطبيق أندرويد باللغة العربية لتنظيم استهلاك الواي فاي اليومي عبر الشبكة المحلية، مع جهاز مشرف وأجهزة مرتبطة.

## البناء التلقائي عبر GitHub Actions
1. ارفع محتويات هذا المجلد (بما فيها مجلد `.github/workflows/android-build.yml`) إلى مستودع GitHub.
2. انتقل إلى تبويب **Actions** في المستودع.
3. سيبدأ البناء تلقائياً (أو اضغط **Run workflow**)، وبعد الانتهاء ستجد ملف `app-debug.apk` جاهزاً للتحميل ضمن **Artifacts**.
